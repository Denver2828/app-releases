# Application releases

Public downloads for Denver2828 applications. Each app has its own stable update manifest and versioned releases.

## Spoty

- Release tags: `spoty-v<version>`.
- Stable channel: `spoty/stable.json` (published after release assets are verified).
- APK variants: ARM64 mobile/Android Auto, ARM32 Sony TV, and universal mobile.
- Each release includes checksums and a corresponding-source archive with license notices.

Existing Spoty installations receive the bridge through the original Outify release channel. The bridge then uses this repository for update discovery.

Do not upload credentials, signing keys, diagnostic logs, private reports, repository backups or Git history here.
